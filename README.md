## Sobre o projeto

Programa desenvolvido em Java como parte das Atividades Práticas Supervisionadas (APS4), com o objetivo de implementar e comparar o desempenho de diferentes algoritmos de ordenação.

O projeto permite analisar o tempo de execução dos algoritmos em diferentes conjuntos de dados, relacionando os resultados ao estudo de estruturas de dados e análise de algoritmos.

## Funcionalidades

- Implementação de Insertion Sort, Merge Sort e Quick Sort.
- Leitura de dados por arquivo ou geração aleatória.
- Testes com sequências aleatórias, ordenadas, reversas e parcialmente ordenadas.
- Medição e comparação dos tempos de execução.
- Configuração de aquecimento e quantidade de execuções.
- Exportação dos resultados em arquivo CSV.

## Tecnologias utilizadas

- **Java:** implementação dos algoritmos e testes.
- **CSV:** armazenamento dos resultados.
- **Excel:** organização e análise dos resultados obtidos.

## Como executar

Com o Java JDK instalado, abra um terminal na pasta principal do projeto e execute:

`mkdir out`

`javac -encoding UTF-8 -d out -sourcepath src src/Main.java`

`java -cp out Main`

O programa apresenta um menu interativo para configuração e realização dos testes.
